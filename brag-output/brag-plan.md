# Plan · video «Build once. Connect any AI.»

- **Qué es:** myStyle, una API local que convierte contenido en PDF, PowerPoint, Word, Excel, video y web para cualquier agente de IA.
- **Para quién:** quien usa Claude Code, Codex, OpenCode, Antigravity o su propio agente y quiere documentos con diseño sin gastar tokens en HTML/CSS.
- **Qué la distingue:** el agente rellena huecos de recetas; el motor dibuja y valida. Un solo motor, las mismas herramientas para cualquier agente.
- **Claim más fuerte (medido):** 94 % menos tokens por PDF frente a hacerlo a mano (`servidor/web/stats/tokens.json`).
- **Gancho (0–5 s):** «La mayoría de agentes solo responden. / Este construye el resultado.»
- **Tono:** brutalismo (estilo `anura`): negro, verde, ocre, crema, Anton; cortes rápidos al pulso de 120 bpm.
- **Sección /brag:** «Haiku trabaja como Opus a bajo precio.»
- **Cierre:** «Build once. Connect any AI.» + «Todo este video fue hecho con myStyle.» (es cierto: lo genera `create_video` con `:::motion`).
- **Duración:** 80 s (con 4 capturas reales de la web) (el guion del usuario pide más que los 20 s de una pieza /brag corta; se recortó a una idea por escena).
