# Guion base: video «Build once. Connect any AI.» (estilo Brag: rápido, mucho impacto, transiciones donde aparecen las herramientas)

Es un guion BASE: adáptalo y mejóralo con criterio de motion design. Duración objetivo 90–120 s (el motor admite hasta 120 s). Cortes de 2–4 s por escena, textos cortos, una idea por escena.
Los logos de marcas NO se descargan: usa el nombre en tipografía (wordmark) o iconos Lucide (`create_resource` tipo icono).

## Intro
«La mayoría de agentes de IA solo responden preguntas. Este proyecto hace algo diferente: entiende lo que quieres crear, elige las herramientas correctas y construye el resultado automáticamente.»

## Transición 1 · El cerebro
Aparecen nombres flotando: Claude Code · Codex · OpenCode · tu propio agente (entran uno tras otro con zoom y blur).
«No importa qué agente de IA utilices. Todos pueden conectarse al mismo motor.»

## Transición 2 · Las herramientas
Las herramientas aparecen como cartas: `list_recipes()` · `create_from_recipe()` · `create_pdf()` · `create_pptx()` · `create_video()` · `render()` · `audit()` · `check_quality()`
«El agente analiza tu petición… y decide qué herramienta utilizar.»

## Transición 3 · El flujo
«Primero piensa.» (cerebro digital) → «Después selecciona la herramienta.» (las herramientas se iluminan) → «La API hace el trabajo.» (un documento que se genera) → «Y solo si es necesario… escala a un modelo más potente.»

## Transición 4 · Compatible con todo
Cambios rápidos: «Claude Code.» «Codex.» «OpenCode.» «O incluso tu propio agente.» Todo termina alrededor de un servidor central.

## Transición 5 · El objetivo
«El objetivo nunca fue reemplazar a Claude.» (pausa) «El objetivo es usar Claude solo cuando realmente aporta valor.» (pausa) «Todo lo repetitivo… lo hace un modelo local.»

## Transición 6 · El aprendizaje
«Cada error… (rojo) …se corrige. (verde) …se guarda. (base de datos) …y el sistema aprende para no repetirlo.»

## Final
«Un solo motor.» / «Cualquier agente.» / «Las mismas herramientas.» / «Menos tokens.» / «Más automatización.»
Pantalla final: **Build once. Connect any AI.**
