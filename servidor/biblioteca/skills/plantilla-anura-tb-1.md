# Estándar (tabla) (plantilla · v1)

Cabecera negra, primera columna en negrita, regla gruesa al final.

**Cuándo usarlo:** Variante TB-1 del diseño anura; se elige en options.variants.tabla.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "tabla": "TB-1"
  }
 }
}
```
