# Tipografía (átomo) (plantilla · v1)

Anton (títulos), Archivo (texto), IBM Plex Mono (datos).

**Cuándo usarlo:** Variante AT-tipo del diseño salvia; se elige en options.variants.átomo.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "átomo": "AT-tipo"
  }
 }
}
```
