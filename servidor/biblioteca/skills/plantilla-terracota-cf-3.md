# Cifra grande (disco) (cifras) (plantilla · v1)

Una cifra gigante con disco.

**Cuándo usarlo:** Variante CF-3 del diseño terracota; se elige en options.variants.cifras.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "cifras": "CF-3"
  }
 }
}
```
