# Franja de peligro (átomo) (plantilla · v1)

Rayas diagonales para marcar zonas.

**Cuándo usarlo:** Variante AT-franja del diseño anura; se elige en options.variants.átomo.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "átomo": "AT-franja"
  }
 }
}
```
