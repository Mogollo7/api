# Vertical + foto (portada) (plantilla · v1)

Palabra vertical gigante y foto a la derecha; la de ANURA y de la referencia «Cine».

**Cuándo usarlo:** Variante CV-1 del diseño anura; se elige en options.variants.portada.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "portada": "CV-1"
  }
 }
}
```
