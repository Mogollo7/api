Palabras una sobre otra rellenando el ancho exacto.

**Cuándo usarlo:** Variante AT-pila del diseño anura; se elige en options.variants.átomo.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "átomo": "AT-pila"
  }
 }
}
```
