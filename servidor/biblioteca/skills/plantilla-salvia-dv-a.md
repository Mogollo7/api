# SaaS: paso numerado (divisor) (plantilla · v1)

Fondo blanco, numeral gigante y titular pesado, como los pasos de la guía.

**Cuándo usarlo:** Variante DV-A del diseño salvia; se elige en options.variants.divisor.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "divisor": "DV-A"
  }
 }
}
```
