# Cartel (portada) (plantilla · v1)

Titular apilado que llena el ancho, bloques de acento, foto y código de barras (cartel brutalista de referencia).

**Cuándo usarlo:** Variante CV-4 del diseño anura; se elige en options.variants.portada.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "portada": "CV-4"
  }
 }
}
```
