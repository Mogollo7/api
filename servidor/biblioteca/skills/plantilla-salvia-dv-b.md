# SaaS: panel oscuro (divisor) (plantilla · v1)

Panel oscuro con degradado violeta y numeral en acento.

**Cuándo usarlo:** Variante DV-B del diseño salvia; se elige en options.variants.divisor.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "divisor": "DV-B"
  }
 }
}
```
