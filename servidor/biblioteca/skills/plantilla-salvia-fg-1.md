# Marco con pie (figura) (plantilla · v1)

Gráfico o imagen en marco duro con pie en caja.

**Cuándo usarlo:** Variante FG-1 del diseño salvia; se elige en options.variants.figura.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "figura": "FG-1"
  }
 }
}
```
