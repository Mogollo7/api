# Bloque «h» (componente · v1.0)

Subtítulo de sección (etiqueta con regla). No repitas el titular de la sección.

**Cuándo usarlo:** Subtítulo de sección (etiqueta con regla). No repitas el titular de la sección.

**Parámetros:**
- `text`: markup (obligatorio) — Subtítulo corto. Máx. 80.

**Ejemplo correcto:**
```json
{
 "type": "h",
 "text": "Interpretación"
}
```

**Error típico:** Pasarse del límite de longitud (text ≤ 80): el motor recorta o reduce con aviso.
