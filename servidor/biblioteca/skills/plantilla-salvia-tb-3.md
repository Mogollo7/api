# Ficha (tabla) (plantilla · v1)

Sin cabecera rellena: etiqueta a la izquierda, valor a la derecha (como «Revisión / Resultado»).

**Cuándo usarlo:** Variante TB-3 del diseño salvia; se elige en options.variants.tabla.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "tabla": "TB-3"
  }
 }
}
```
