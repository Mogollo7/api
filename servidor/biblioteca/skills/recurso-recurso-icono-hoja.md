# Icono icono-hoja (recurso · v1)

Recurso gráfico «icono» 400×400, colores #2F7D5B sobre none.

**Cuándo usarlo:** Bloque figure con src «recursos/icono-hoja.png»; úsalo de fondo o separador.

**Ejemplo correcto:**
```json
{
 "type": "figure",
 "src": "recursos/icono-hoja.png",
 "alt": "icono decorativo"
}
```
