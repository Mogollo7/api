# Imagen con crédito (figura) (plantilla · v1)

Foto en dos tintas con pie y crédito.

**Cuándo usarlo:** Variante FG-3 del diseño editorial; se elige en options.variants.figura.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "figura": "FG-3"
  }
 }
}
```
