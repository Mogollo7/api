# Portada color pleno (portada) (plantilla · v1)

Portada con fondo acento, generada por fabrica_estilo.py.

**Cuándo usarlo:** Variante CV-3 del diseño terracota; se elige en options.variants.portada.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "portada": "CV-3"
  }
 }
}
```
