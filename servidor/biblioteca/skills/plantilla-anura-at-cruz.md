# Marca de cruz (átomo) (plantilla · v1)

Cruz fina de registro, suelta.

**Cuándo usarlo:** Variante AT-cruz del diseño anura; se elige en options.variants.átomo.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "átomo": "AT-cruz"
  }
 }
}
```
