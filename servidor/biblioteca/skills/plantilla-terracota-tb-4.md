# Matriz de tonos (tabla) (plantilla · v1)

Celdas con tono F / P / L / —, legible en grises por la letra.

**Cuándo usarlo:** Variante TB-4 del diseño terracota; se elige en options.variants.tabla.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "tabla": "TB-4"
  }
 }
}
```
