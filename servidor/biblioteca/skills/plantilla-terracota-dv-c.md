# Divisor color pleno (divisor) (plantilla · v1)

Divisor con fondo acento, generada por fabrica_estilo.py.

**Cuándo usarlo:** Variante DV-C del diseño terracota; se elige en options.variants.divisor.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "divisor": "DV-C"
  }
 }
}
```
