# Prompt Master · editorial SaaS (estilo · v0.1.1)

Familia visual «editorial-saas»: 7 colores por rol, fuentes Archivo, contraste mínimo 4.5:1.

**Cuándo usarlo:** Elige el estilo cuando el usuario no trae uno; si trae una imagen, busca el parecido.

**Parámetros:**
- `roles`: color por rol (negro, bosque, hoja, vivo, ocre, crema, arena)
- `formatos`: pdf-a4, pptx-16x9

**Ejemplo correcto:**
```json
{
 "design": "prompt-master",
 "palette": "default"
}
```
