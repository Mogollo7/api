# Tarjetas (cifras) (plantilla · v1)

2 a 4 tarjetas con cifra grande.

**Cuándo usarlo:** Variante CF-1 del diseño anura; se elige en options.variants.cifras.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "cifras": "CF-1"
  }
 }
}
```
