# Compacta (tabla) (plantilla · v1)

Letra menor y relleno corto para tablas largas.

**Cuándo usarlo:** Variante TB-2 del diseño anura; se elige en options.variants.tabla.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "tabla": "TB-2"
  }
 }
}
```
