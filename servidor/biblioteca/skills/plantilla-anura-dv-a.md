# Disco (divisor) (plantilla · v1)

Foto circular que sangra abajo a la derecha

**Cuándo usarlo:** Variante DV-A del diseño anura; se elige en options.variants.divisor.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "divisor": "DV-A"
  }
 }
}
```
