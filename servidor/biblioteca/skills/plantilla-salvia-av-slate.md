# Atención (pizarra) (aviso) (plantilla · v1)

Aviso con regla interior, como «Riesgo de desbordamiento»

**Cuándo usarlo:** Variante AV-slate del diseño salvia; se elige en options.variants.aviso.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "aviso": "AV-slate"
  }
 }
}
```
