# Foto en esquina (divisor) (plantilla · v1)

Foto en la esquina inferior derecha

**Cuándo usarlo:** Variante DV-D del diseño anura; se elige en options.variants.divisor.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "divisor": "DV-D"
  }
 }
}
```
