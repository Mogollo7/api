# Ficha de datos (formulario) (plantilla · v1)

Barra negra con filas para completar (como «Datos del estudiante»).

**Cuándo usarlo:** Variante FM-1 del diseño terracota; se elige en options.variants.formulario.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "formulario": "FM-1"
  }
 }
}
```
