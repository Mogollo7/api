# Punto clave (hoja) (plantilla · v1)

Hoja con tarjeta bosque al inicio y etiqueta en la cabecera.

**Cuándo usarlo:** Variante HJ-2 del diseño salvia; se elige en options.variants.hoja.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "hoja": "HJ-2"
  }
 }
}
```
