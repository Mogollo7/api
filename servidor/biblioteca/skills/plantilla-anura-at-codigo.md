# Código de barras (átomo) (plantilla · v1)

Generado de un texto semilla; vectorial.

**Cuándo usarlo:** Variante AT-codigo del diseño anura; se elige en options.variants.átomo.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "átomo": "AT-codigo"
  }
 }
}
```
