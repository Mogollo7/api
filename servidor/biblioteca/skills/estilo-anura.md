# ANURA · brutalista (estilo · v0.2.0)

Familia visual «brutalismo»: 7 colores por rol, fuentes Anton, Archivo, IBM Plex Mono, contraste mínimo 4.5:1.

**Cuándo usarlo:** Elige el estilo cuando el usuario no trae uno; si trae una imagen, busca el parecido.

**Parámetros:**
- `roles`: color por rol (negro, bosque, hoja, vivo, ocre, crema, arena)
- `formatos`: pdf-a4, pptx-16x9

**Ejemplo correcto:**
```json
{
 "design": "anura",
 "palette": "default"
}
```
