# Columna lateral (cifras) (plantilla · v1)

Cifras en columna con regla vertical, al lado de una figura.

**Cuándo usarlo:** Variante CF-2 del diseño salvia; se elige en options.variants.cifras.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "cifras": "CF-2"
  }
 }
}
```
