# Franja + goteo (divisor) (plantilla · v1)

Franja de foto con goteos abajo

**Cuándo usarlo:** Variante DV-B del diseño anura; se elige en options.variants.divisor.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "divisor": "DV-B"
  }
 }
}
```
