# Color por roles (átomo) (plantilla · v1)

Siete roles: negro, bosque, hoja, vivo, ocre, crema, arena.

**Cuándo usarlo:** Variante AT-color del diseño terracota; se elige en options.variants.átomo.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "átomo": "AT-color"
  }
 }
}
```
