# Contorno + cartel (divisor) (plantilla · v1)

Número en contorno y franja lateral

**Cuándo usarlo:** Variante DV-C del diseño anura; se elige en options.variants.divisor.

**Ejemplo correcto:**
```json
{
 "options": {
  "variants": {
   "divisor": "DV-C"
  }
 }
}
```
